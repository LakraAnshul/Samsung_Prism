Problem Identification

The Gap in Standard Multimodal RAG

Why traditional unconstrained RAG pipelines fail in technical appliance domains

02 / 12
Flawed Baseline Architecture
  • Two Independent Searches: Text and image retrieval ran separately with zero grounding connection.
  • Unconstrained Queries: "Samsung washer" queries cross-pollinated top-load and front-load manuals.
  • Forced Bad Matches: Pipeline always attached an image even when zero relevant diagrams existed.
  • Severe Repetition: Same pump diagram repeated across 6 unrelated steps.
Our Solution Architecture
  • Model Disambiguation: Enforces model number validation & slot-filling prior to vector search.
  • Spatial Linked Ingestion: Images and text chunks bound at PDF parse time via page & bbox.
  • Confidence Rejection: Return clean, pristine text if match similarity is <0.65.
  • Zero Duplicate Guarantee: Suppresses image reuse across consecutive steps.

Precision Defense

Confidence Rejection & Duplicate Suppression

Transforming bad visual attachments into clean, reliable text instructions

06 / 12
Confidence Rejection Threshold (<0.65)

Most troubleshooting steps (e.g. "Unplug the washing machine from wall outlet" or "Wait 5 minutes") do not have diagrams in the official manual.

Instead of forcing a random unrelated machine photo, the engine returns images: null with rejection_reason: "low_visual_confidence".

Duplicate Suppression Filter

Baseline RAG repeated the same image on 80% of steps. Our engine tracks all attached image paths within the session.

Re-attaching an already used image requires an overwhelming similarity score (≥ 0.92), reducing the repetition rate to 0.0%.
